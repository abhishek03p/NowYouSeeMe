## 💡 How Meeting Code Works

**Format**: 8-character uppercase alphanumeric (e.g., `ABC12345`)

**Generated by**: `/api/meetings/create` endpoint

**Validation**: `/api/meetings/{code}/exists` endpoint checks if meeting exists

**Scope**: Meeting lives as long as at least one participant is connected
- When last person leaves → meeting is deleted
- New meeting code needed for new session

## 🔧 Troubleshooting

### Landing Page Not Showing
```bash
# Hard refresh
Ctrl+Shift+R (Windows/Linux)
Cmd+Shift+R (Mac)

# Check server is running
curl http://localhost:8080
```

### Can't Join Meeting
- Verify meeting code is correct (uppercase)
- Check both users are using same meeting ID
- Both must grant camera/mic permissions

### Audio/Video Not Working
1. Check browser console for errors (F12)
2. Verify camera/mic permissions granted
3. Try hard refresh + clear cache
4. Try different browser
5. Check console for track logs

### Error: "Meeting Not Found"
- Meeting code might be wrong
- First user may have disconnected
- Create a new meeting
