🎯 COMMAND CHEAT SHEET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STARTING:
├─ mvn spring-boot:run              → Start with Maven
├─ java -jar target/*.jar           → Start pre-built JAR
├─ mvn spring-boot:run &            → Start in background
└─ mvn spring-boot:run -D...=3000   → Custom port 3000

STOPPING:
├─ Ctrl + C                         → Normal stop
├─ kill -9 <PID>                   → Force kill by PID
├─ pkill -f NowyouseemeApplication  → Kill by name
├─ lsof -ti:8080 | xargs kill -9   → Kill by port
└─ killall java                    → Kill all Java

BUILDING:
├─ mvn clean compile                → Compile
├─ mvn clean package                → Build JAR
├─ mvn clean package -DskipTests    → Skip tests
└─ mvn dependency:resolve           → Download deps

CHECKING:
├─ curl http://localhost:8080       → Test if running
├─ lsof -i :8080                   → Show port users
├─ ps aux | grep java              → List Java processes
├─ java -version                    → Check Java version
└─ mvn -version                     → Check Maven version

CUSTOM PORTS:
├─ mvn spring-boot:run -Dspring-boot.run.arguments="--server.port=3000"
├─ java -Dserver.port=3000 -jar target/*.jar
└─ export SERVER_PORT=3000; mvn spring-boot:run

LOGGING:
├─ mvn spring-boot:run -X           → Debug mode
├─ mvn spring-boot:run -e           → Show errors
└─ mvn spring-boot:run -q           → Quiet mode
